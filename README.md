# Mu-Ko Chou Academic Website

Astro source for a personal academic GitHub Pages site.

Live site: https://claire891018.github.io

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

The included GitHub Actions workflow deploys the Astro `dist/` output on each push to `main`.

Update `src/data/site.ts` with your final GitHub profile, Google Scholar, LinkedIn, and paper links before sharing the site.
